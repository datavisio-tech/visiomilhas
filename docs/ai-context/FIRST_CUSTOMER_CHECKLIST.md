# First Customer Checklist

## Goal

Prepare the first real customer onboarding with the least friction possible.

## Before invite

- Verify HM or PROD environment is healthy.
- Verify the Google OAuth console has the correct redirect URIs.
- Verify the subscription gating is working.
- Verify the initial onboarding flow is accessible.

## First login

1. User authenticates successfully.
2. Session is created.
3. Organization context is created or resolved.
4. User lands on onboarding or dashboard according to current state.

## First operational setup

1. Create the first account.
2. Choose the correct points program.
3. Register initial balance if needed.
4. Create the first purchase or import the first movement.
5. Confirm dashboard metrics render without errors.

## First trial

1. Open Subscribe.
2. Activate trial.
3. Confirm access changes to `TRIAL`.
4. Confirm the 15-day window is visible.
5. Confirm the user can continue the operational flow.

## First support touchpoints

- explain how to create accounts
- explain what happens after the trial
- explain the difference between monthly and annual billing
- explain how cancelation behaves
- explain how data stays preserved

## Success criteria

- user logs in without friction
- first organization is created
- first account exists
- trial is visible and understandable
- dashboard becomes useful quickly
- support can explain the flow in one pass
